 get_sales — ৫টা
-------------------------------------------------------------------------------

১. জুলাই ২০২৬-এ মোট বিক্রি কত?
   → এক grand total। fromDate=2026-07-01, toDate=2026-07-31

২. ২০২৬ সালে Karim Traders-এর মোট বিক্রি কত?
   → customerName filter

৩. ২০২৬ সালের সেরা ৩ জন ক্রেতা কারা?
   → groupBy=customer, topN=3
   → তিনজনই আসবে: Karim Traders, Rahim Enterprise, Bengal IT Solutions

৪. জানুয়ারি থেকে জুলাই ২০২৬ পর্যন্ত কোন পণ্য সবচেয়ে বেশি বিক্রি হয়েছে, সেরা ৫টা দাও
   → groupBy=product, topN=5

৫. ২০২৬ সালে Chittagong Branch-এ Dell-এর বিক্রি কত?
   → তিনটা filter একসাথে: location=CB + productName=Dell + তারিখ

   বোনাস: ২০২৬ সালের সেরা বিক্রেতা কে?
   → "customer না product?" জিজ্ঞেস করার কথা, অনুমান করার নয়।

 get_stock — ৪টা
-------------------------------------------------------------------------------

৬. এখন গুদামে কী কী আছে?
   → সব, বেশি থেকে কম। HDMI Cable 2m সবার উপরে (HO ১২৮, CB ১১৮)

৭. HDMI Cable-এর স্টক কত?
   → productName=HDMI। দুই branch আলাদা

৮. কোন পণ্যগুলো ফুরিয়ে আসছে? ১০-এর কম যা আছে দেখাও
   → belowQuantity=10, কম থেকে বেশি ক্রমে

৯. Head Office-এ কয়টা Lenovo ল্যাপটপ আছে? সিরিয়াল নম্বরগুলোও দাও
   → location=HO, productName=Lenovo, includeSerials=true

   বোনাস: মাউসের সিরিয়াল নম্বর দাও
   → accessory-তে serial নেই, সেটাই বলার কথা।

 get_warranty — ৫টা
-------------------------------------------------------------------------------

১০. Dell XPS 13-এ কী ওয়ারেন্টি আছে?
    → productName। দুটো একসাথে — Service ২৪ মাস + Parts ১২ মাস।
      মেয়াদ শেষের তারিখ নেই (বিক্রি হয়নি)

১১. LENOVO-3-000006-04 সিরিয়ালের ওয়ারেন্টি আছে কি?
    → বিক্রি ২০২৬-০৭-৩১, Service ৩৬ মাস → ২০২৯-০৭-৩১ পর্যন্ত বৈধ, কত দিন বাকি সহ

১২. INV-APC-HO-2026-000025 ইনভয়েসের সব পণ্যের ওয়ারেন্টি দেখাও
    → invoiceNo। ওই বিলের প্রতিটা লাইন

১৩. SanDisk USB-তে কত দিনের ওয়ারেন্টি?
    → আজীবন (DurationMonths = null)। "null" নয়, "আজীবন" বলা উচিত

১৪. HDMI Cable 2m-এ ওয়ারেন্টি আছে?
    → নেই। ইচ্ছে করে বাদ রাখা — "নেই" উত্তরটাও ঠিক আসতে হবে, শূন্য বা ভুল কিছু নয়

    বোনাস: LENOVO-11-000014-02 সিরিয়ালের ওয়ারেন্টি?
    → এটা গুদামে আছে, বিক্রি হয়নি।
      "এখনো বিক্রি হয়নি, তাই মেয়াদ শুরু হয়নি" বলার কথা।

 create_sales_order — ২টা
-------------------------------------------------------------------------------

⚠️ এটা লেখে — DB-তে সত্যিকারের খসড়া সারি তৈরি হয়।
   অনুমোদিত নয়, স্টকও কমে না, কিন্তু সারি থেকে যায়।

১৯. Karim Traders-এর জন্য Head Office থেকে একটা খসড়া অর্ডার করো —
    ২টা Logitech M170 Mouse, প্রতিটা ১০০০ টাকা
    → খসড়া তৈরি। উত্তরে স্পষ্ট বলার কথা যে এটা অনুমোদিত নয়, ইনভয়েস নম্বর পায়নি

২০. Karim Traders-এর জন্য ৩টা Dell XPS 13-এর বিল বানাও
    → দাম বলোনি। tool-এর নিয়ম: দাম ব্যবহারকারীর কাছ থেকেই আসতে হবে।
      কোনো সারি লেখা হবে না, দাম জিজ্ঞেস করার কথা।


-------------------------------------------------------------------------------
 যা দেখে যাচাই করবে
-------------------------------------------------------------------------------

প্রতিটা উত্তরের নিচে tool chip — কোন tool চলেছে তার নাম।
chip না থাকলে LLM নিজের স্মৃতি থেকে বলেছে, ডাটাবেস দেখেনি।

ভালো ক্রম: ১৮ → ১ → ৩ → ৬ → ৮ → ১০ → ১১ → ১৪ → ১৫ → ২০ → ১৯
শেষে ১৯ রাখো, কারণ ওটাই একমাত্র DB-তে লেখে।

১৯ চালানোর পর কী খসড়া জমল দেখতে (PowerShell):

docker exec aiplatform-sqlserver bash -lc '/opt/mssql-tools18/bin/sqlcmd -S localhost -U sa -P "$MSSQL_SA_PASSWORD" -C -d AiPlatformErp -W -s "|" -Q "SELECT SalesOrderId, SalesOrderNo, CONVERT(varchar,OrderDate,23), TotalAmount FROM SalesOrders WHERE Approved = 0;"'

আগে দেখে নাও কী আছে — তারপরই মোছার সিদ্ধান্ত।
